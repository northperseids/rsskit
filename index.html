• PluralKit Fronters RSS Feed
    So friends can use RSS feeds to see who's fronting!

    Transparently, I don't have a huge personal infrastructure and I am one* person! It might be slow! It might be buggy! (It's also on GitHub if you want to try to host your own.)

    You will need to submit your token for authorization to create a feed, but tokens are not saved and no private information can be retrieved from PluralKit in feeds.

    With that said, you'll need the privacy for CURRENT FRONTER set to public. Tokens are only used to authenticate directly with PluralKit's API to make sure the actual owner of the PluralKit system is the only one who can register an RSS feed for that system. The only data saved is an automatically-generated database entry ID, your 5-6 letter PK ID, and the day you created the feed.

    Input your system ID and your PK token, then click Create. You will be directed to an XML RSS feed. Copy the URL and paste it into your RSS feed reader.

    If you lose your feed URL, it's always going to be https://rsskit.neartsua.me/feeds/feed.php?id=[SYSTEMID] where [SYSTEMID] is your PluralKit system ID! You can also resubmit with your ID and token if you want.

    If you want to remove your RSS feed, enter your system ID and token, and then click Remove instead.
